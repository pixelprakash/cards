How the game is being played

Every play is a hand: one challenge, four chosen cards, the questions the game wrote and what the player answered. This page counts them.

Sign in

This page is for the research team. Enter the user ID and password you were given.

Counts about cards and hands use finished plays. The funnel and the totals use every play that started. Each player is a random id kept in their browser, with the age band, gender and optional name they gave before playing, and an optional group code. Written answers can contain personal details, so treat this page and its downloads as research data.
